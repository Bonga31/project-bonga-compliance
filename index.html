Project Bonga API Client

Project Bonga is a locally operated content-production and publishing workflow

used by Matthew Owen to manage videos for the Strange Britain YouTube

channel.

What it does

  • Prepares a creator-approved MP4, title, description, tags and audience setting.
  • Shows the exact upload and visibility settings before any YouTube write action.
  • Requires an explicit human approval before uploading or scheduling.
  • Uses OAuth 2.0 to access only the creator's own authorised YouTube channel.
  • Records the resulting YouTube video ID for release tracking.

What it does not do

  • It is not a public multi-user service.
  • It does not request or store a YouTube password.
  • It does not collect viewer identities, browsing history or location.
  • It does not download, alter or re-host YouTube videos.
  • It does not automate likes, comments, subscriptions or views.
  • It does not circumvent YouTube restrictions.
