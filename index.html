﻿# Project Bonga API Client

Project Bonga uses YouTube API Services.

Project Bonga is a locally operated Windows desktop workflow used by

Matthew Owen to manage creator-approved uploads for the Strange Britain

YouTube channel.

YouTube functionality

  • The user defines and reviews the title and description.
  • The user selects Private, Unlisted, Public or scheduled-public visibility.
  • The exact video, audience setting, visibility and schedule are displayed.
  • A YouTube write action requires an explicit final approval phrase.
  • OAuth 2.0 authorises access to the operator's own channel.
  • Non-private API actions remain disabled until written audit approval.

User control

The user must accept the Privacy Policy and Terms of Use before first use.

Project Bonga includes a disconnect command that deletes its local OAuth token

and locally stored YouTube API records while preserving locally created video

and research files.

What Project Bonga does not do

  • It is not a public multi-user service.
  • It does not request or store a Google or YouTube password.
  • It does not collect viewer identities, viewing history or location.
  • It does not automate likes, comments, subscriptions or views.
  • It does not download or re-host YouTube content.
  • It does not use cookies, advertising or third-party tracking on this site.
  • It does not circumvent YouTube restrictions.
