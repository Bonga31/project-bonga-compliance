Privacy Policy

Effective date: 25 July 2026

Project Bonga is a local desktop API client operated by Matthew Owen in

the United Kingdom.

YouTube API Services

Project Bonga uses YouTube API Services. Use of Project Bonga is also subject

to the YouTube Terms of Service:

https://www.youtube.com/t/terms

Google's Privacy Policy is available at:

https://policies.google.com/privacy

Information accessed

Project Bonga uses OAuth 2.0 authorisation to upload creator-approved videos to

the authorising user's YouTube channel. It may process:

  • the authorised YouTube channel identity;
  • the local video selected for upload;
  • video metadata approved by the user, including title, description, tags,

category, audience setting, privacy setting and scheduled publication time;

  • the video ID and upload status returned by YouTube.

Project Bonga does not request or store the user's Google or YouTube password.

Purpose

The information is used only to upload, schedule and record videos on the

authorising user's own YouTube channel.

Storage

OAuth credentials and upload records are stored locally on the operator's

computer. OAuth client secrets and tokens are excluded from the source-code

repository. Project Bonga does not sell personal information or share

authorised YouTube data with advertisers or unrelated third parties.

Control and consent

Before an upload or scheduling action, Project Bonga displays the selected

channel, video, title, privacy setting and publication time. The user must give

an explicit approval before the action proceeds.

The user may revoke Project Bonga's Google account access at:

https://myaccount.google.com/permissions

The user may request deletion of locally stored authorisation and upload

records by contacting matthewowen1@gmail.com. Requests will be handled within 30

days.

Retention

OAuth tokens are retained only while Project Bonga remains authorised. Upload

records are retained for the creator's production audit trail and can be

deleted on request. Authorised API data is not retained indefinitely without a

continuing operational need.

Security

Project Bonga stores credentials locally, does not embed them in public source

code and limits OAuth access to the scopes needed for its stated function.
