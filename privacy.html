Privacy Policy

Effective date: 27 July 2026

Project Bonga is a local Windows desktop API client operated by

Matthew Owen in the United Kingdom.

YouTube API Services

Project Bonga uses YouTube API Services. Use of Project Bonga is also subject

to the YouTube Terms of Service:

https://www.youtube.com/t/terms

Google's Privacy Policy is available at:

https://policies.google.com/privacy

Information accessed and stored

Project Bonga uses OAuth 2.0 authorisation to upload creator-approved videos to

the authorising user's own YouTube channel. It may process:

  • the local video selected by the user;
  • the title, description, tags, category and audience setting defined by the

user;

  • the selected visibility and optional scheduled publication time;
  • the video ID and upload status returned by YouTube;
  • a local record of policy acceptance and OAuth authorisation.

Project Bonga does not request, collect or store the user's Google or YouTube

password. It does not collect viewer identities, viewing history, location,

contacts or unrelated Google account information.

Purpose

The information is used only to validate, upload, schedule and locally record

videos on the authorising user's own YouTube channel.

User consent and control

Before first use, Project Bonga displays links to this Privacy Policy and the

Terms of Use and requires the user to type `I AGREE`.

Before every YouTube write action, Project Bonga displays the selected video,

title, full description, audience setting, visibility, schedule and

subscriber-notification choice. The user must enter a specific approval phrase

before the action proceeds and may cancel without an API request.

Storage and sharing

OAuth credentials and upload records are stored locally on the operator's

computer. OAuth client secrets and tokens are excluded from the source-code

repository.

Project Bonga does not sell authorised data, share it with advertisers or

provide it to unrelated third parties. The public compliance website uses no

cookies, advertising or third-party analytics.

Revocation, disconnection and deletion

The user may revoke Project Bonga's Google account access at:

https://myaccount.google.com/permissions

Project Bonga provides a local `disconnect-youtube.ps1` command. It deletes the

local OAuth token, local policy-consent record and locally stored YouTube API

upload and release records. It preserves local videos, scripts, research and

licensed assets.

Deleting Project Bonga's local data does not delete any video or other data

stored by YouTube. Data stored by YouTube must be deleted through YouTube or

another authorised client that supports deletion.

A deletion request may also be sent to matthewowen1@gmail.com. Valid requests will be

completed as soon as possible and within seven calendar days.

Retention

OAuth tokens are retained only while Project Bonga remains authorised. Local

YouTube API records are retained only for the creator's operational audit

trail and are deleted when the user invokes the deletion control, withdraws

authorisation or makes a valid deletion request.

Security

Project Bonga stores credentials locally, excludes secrets and tokens from

version control, uses Google's OAuth flow and requests only the YouTube upload

scope needed for its stated purpose.
